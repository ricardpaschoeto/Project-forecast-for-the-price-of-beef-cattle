# 🐂 Boi Gordo Price Forecast

Projeto de Machine Learning para previsão do preço da arroba do boi gordo no Brasil utilizando dados de mercado, indicadores macroeconômicos, variáveis climáticas e sazonalidade.

---

## Objetivo

Construir um sistema automatizado capaz de prever a evolução do preço da arroba do boi gordo utilizando técnicas modernas de Data Engineering, Machine Learning e MLOps.
